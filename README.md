# codex-demo

该仓库包含用于 Excel 序时账快速定位的 VBA 代码示例：

- `excel/vba/ThisWorkbook.cls`：在工作簿打开时，将“科目余额表”工作表的 A、B 列固定为文本格式。
- `excel/vba/Sheet科目余额表.cls`：在“科目余额表”工作表中响应激活、修改和双击事件。
- `excel/vba/modLedgerNavigation.bas`：提供统一的格式修复与序时账跳转逻辑。
- `excel/background.xsto`：描述需求背景与解决方案摘要。

将这些模块导入到目标工作簿后，可实现：

1. “科目余额表”中 A、B 列始终保持文本格式，避免双击后出现补零或自动格式化。
2. 双击 A 列科目编码或 B 列科目名称时，自动定位到“序时账”工作表中匹配的分录。
3. 如果未找到匹配项，将弹出提示，提醒用户检查数据。

> **提示**：确保目标工作簿包含名为“科目余额表”和“序时账”的工作表，并且序时账中的科目编码或名称与科目余额表中的内容一致。
